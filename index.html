מפעילים את השרת

  1. לוחצים על הכפתור הירוק למעלה ומורידים את קובץ ה-ZIP.
  2. לחיצה ימנית על קובץ ה-ZIP ← חלץ הכל (Extract All). נכנסים לתיקייה My-Server שנוצרה.
  3. פעם אחת בלבד – מבטלים חסימה:
    א. לחיצה ימנית על הקובץ start ← בתפריט שנפתח לוחצים מאפיינים (העיגול האדום).
    ב. בחלון שנפתח, למטה: מסמנים את הריבוע ליד בטל חסימה ‏(1), ולוחצים אישור ‏(2).
  4. לחיצה כפולה על start. בפעם הראשונה נפתח חלון קטן שמוריד את Java (כמה דקות). מהפעם השנייה – אין חלונות.
  5. לוח הבקרה נפתח לבד בדפדפן – לוחצים ▶ הפעל, וכשכתוב "באוויר!" משחקים. אם Windows שואל על חומת אש – מאשרים.
  1. לוחצים פעמיים על קובץ ה-ZIP כדי לפתוח אותו.
  2. לחיצה ימנית (או Control+לחיצה) על start.command ← פתח.
  3. אם macOS חוסם: הגדרות מערכת ← פרטיות ואבטחה ← פתח בכל זאת. דרך חלופית שתמיד עובדת: פותחים Terminal, גוררים אליו את התיקייה אחרי cd , ואז bash start.sh
  4. בפעם הראשונה מורידים לבד את Java ואת תוכנת השרת, ואז נפתח לוח הבקרה בדפדפן – לוחצים ▶ הפעל.
  1. unzip לקובץ, ואז בטרמינל בתוך התיקייה: bash start.sh
  2. נפתח לוח בקרה בכתובת http://localhost:8123 – לוחצים ▶ הפעל.
  3. אם יש חומת אש: לפתוח TCP 25565 ו-UDP 19132.

לוח הבקרה לא נפתח? פותחים בדפדפן את http://localhost:8123 (או לוחצים שוב על start.bat). סגרתם את הדפדפן? השרת ממשיך לעבוד – לחיצה על start.bat פותחת את הלוח שוב. לכיבוי מלא: ⏻ סגור הכל בלוח הבקרה.

מתחברים ומשחקים

JAVA מחשב

  1. Multiplayer ← Add Server.
  2. באותו מחשב: localhost. מחשב אחר באותה רשת: הכתובת שהשרת מציג, לדוגמה 192.168.1.20
  3. צריך את אותה גרסת Java של השרת (בדרך כלל האחרונה).

BEDROCK טלפון / Windows / טאבלט

  1. Play ← Servers ← Add Server.
  2. כתובת: ה-IP שהשרת מציג (גם באותו מחשב – לא localhost). פורט: 19132
  3. בלי חשבון Java – Floodgate מכניס שחקני Bedrock עם חשבון Microsoft.

WEB חברים מבית אחר

  1. הדרך הקלה: playit.gg (חינם) – מתקינים, יוצרים מנהרה מסוג Minecraft Java לפורט 25565 ומסוג Minecraft Bedrock לפורט 19132, ונותנים לחברים את הכתובת שמתקבלת.
  2. או: העברת פורטים בנתב (TCP 25565 + UDP 19132) ונותנים לחברים את ה-IP החיצוני שלכם.

שאלות נפוצות

איך אני נהיה מנהל (אדמין) בשרת?

בחלון השרת מקלידים op YourName. לשחקן Bedrock יש נקודה לפני השם: op .YourName

הפעלתי "רק חברים מאושרים" – איך מוסיפים חבר?

שחקן Java: whitelist add Name. שחקן Bedrock: fwhitelist add Name (פקודה של Floodgate).

איך מעדכנים לגרסה חדשה?

מכבים את השרת, מוחקים את paper.jar (ואת שני הקבצים בתיקייה plugins) ומפעילים שוב – הגרסה החדשה יורדת לבד. מומלץ לגבות קודם את התיקיות world.

Xbox / PlayStation / Switch?

בקונסולות אין כפתור "הוסף שרת". אפשר להשתמש באפליקציה חינמית כמו BedrockTogether בטלפון שנמצא באותה רשת – הקונסולה תראה את השרת כמשחק LAN.

זה באמת בחינם? מה זה מוריד?

כן. הכל תוכנות קוד פתוח רשמיות: Paper (שרת Java מהיר, papermc.io), Geyser + Floodgate (גשר ל-Bedrock, geysermc.org) ו-Java 25 מ-Adoptium. הן יורדות ישירות מהאתרים הרשמיים בהפעלה הראשונה, והשרת רץ על המחשב שלכם – בלי מנוי ובלי הגבלת זמן.

השרת לא עולה / שגיאה

פותחים את logs/latest.log בתיקיית השרת. בעיות נפוצות: לא סימנתם EULA, אין חיבור לאינטרנט בהפעלה הראשונה, או שתוכנה אחרת כבר משתמשת בפורט 25565 (שרת אחר שכבר פתוח).
